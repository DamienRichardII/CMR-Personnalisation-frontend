# E-mails d’authentification Supabase — CMR Personnalisation

À coller dans Supabase : Authentication → Emails → Templates. Pour chaque modèle : remplacer le sujet (Subject) et le contenu (Message body, mode HTML source) par ceux ci-dessous. Ne pas modifier les variables {{ ... }}.

| Modèle Supabase | Fichier | Sujet |
|---|---|---|
| Confirm signup | confirmation.html | Confirmez votre adresse e-mail — CMR Personnalisation |
| Reset password | recovery.html | Réinitialisation de votre mot de passe — CMR Personnalisation |
| Magic link | magic-link.html | Votre lien de connexion — CMR Personnalisation |
| Change email address | changement-email.html | Confirmez votre nouvelle adresse e-mail — CMR Personnalisation |
| Invite user | invitation.html | Vous êtes invité — CMR Personnalisation |
| Reauthentication | reauthentification.html | Votre code de vérification — CMR Personnalisation |
